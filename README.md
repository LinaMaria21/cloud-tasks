# Cloud Tasks ☁️

A full-stack cloud application built to learn and demonstrate modern AWS cloud engineering.

## Architecture

- React + TypeScript frontend
- Amazon S3 + CloudFront
- Python + FastAPI REST API
- Docker
- Amazon ECR
- Amazon ECS + Fargate
- PostgreSQL / Amazon RDS
- AWS CDK
- GitHub Actions CI/CD
- Amazon CloudWatch
- IAM

## Project Goal

This project is a hands-on learning project focused on containerized AWS applications, Infrastructure as Code, CI/CD, monitoring, and cloud troubleshooting.
